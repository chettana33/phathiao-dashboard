# 🗓️ ลำดับถัดไป (Roadmap)

> เส้นทางจากวันนี้ ไปหาลูกค้าใหม่ผ่าน Ichino Tour

## ลำดับหลัก (ตกลงกับพี่เจแล้ว)

1. **Master Data เสร็จ** — ปลดล็อกทุกอย่าง (ราคาตอบไว = quotation ไว = ปิดดีลไว)
2. **Master Data → ป้อนเข้า** quotation (ราคาจริง) + เว็บ (content จริง) + JLOS (Hotel/Bus module)
3. **B2B outreach** — เริ่ม Smile Travel (#40, ลูกค้าเก่า ต่อยอดง่ายสุด) → 50 เจ้าใน Target List
4. **ต่อยอดลูกค้าเก่า** — HAI (26 ธ.ค. 69) · ma-meow (ม.ค. 70) — ใช้เป็น case study
